## Importing the calendar

1. Open [calendar.google.com](https://calendar.google.com) on desktop
2. Settings → Import & export → Select file
3. Pick `exam_schedule.ics`, choose target calendar, click Import

Reminders pre-set: 30 min before exams, 10 min before study sessions.

## Hosting the tracker

Enable GitHub Pages in repo Settings → Pages → Branch: `main`, folder: `/` (root).
The tracker will be live at `https://<your-username>.github.io/<repo-name>/`.
